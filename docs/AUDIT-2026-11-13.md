# Audit 2026-11-13: Leistung, Gestaltung, Code

Aufbauend auf [`AUDIT-2026-11-06.md`](AUDIT-2026-11-06.md) und den Leistungsrunden vom 10./11.11.
Branch `claude/quirky-rubin-25sstg`, Linux-Container, Python 3.13, PySide6 6.12.0, `QT_QPA_PLATFORM=offscreen`.

**Einordnung:** Der Auftrag war auf eine Website zugeschnitten (Core Web Vitals, Video-Streaming,
Bildformate, CDN, Zeitzeugen-Archiv). Zeitzeuge ist eine Windows-Desktop-App (Qt) zur
Zeiterfassung für IT-Consultants. Die Web-Kriterien sind deshalb auf ihre Desktop-Entsprechung
übertragen: Startzeit statt LCP, Reaktionszeit und Arbeit im GUI-Thread statt INP, Layout-Sprünge
und Scrollleisten statt CLS, Qt-Barrierefreiheit statt Lighthouse (siehe `quality-guardrails.md`).
Nicht anwendbar: CDN, Brotli/Gzip, Bild-/Video-/Audio-Formate, SEO und strukturierte Daten.
